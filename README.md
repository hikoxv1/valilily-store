# ValiLily — інтернет-магазин квітів

Навчальний вебпроєкт на React + Vite, підготовлений для публікації на GitHub Pages.

## Що реалізовано
- адаптивний дизайн українською мовою;
- каталог із 18 позиціями, категоріями, пошуком і сортуванням;
- кошик зі зміною кількості товарів і підрахунком суми;
- форма індивідуального замовлення;
- оформлення замовлення через підготовлений лист `mailto`;
- інформаційні блоки про бренд і доставку;
- авторський підвал на сторінці.

## Важливо про замовлення
GitHub Pages — статичний хостинг. Кошик працює в браузері, а кнопки замовлення відкривають поштову програму з підготовленим листом на адресу, зазначену у футері. Автоматична відправка без поштового сервісу або серверної частини не виконується. Для реального приймання заявок варто підключити Formspree, EmailJS або власний сервер і перевірити адресу отримувача.

Ціни та асортимент у каталозі — демонстраційні орієнтири, які потрібно підтвердити перед реальним продажем. Доступність квітів і їхній склад можуть змінюватися.

## Запуск локально
1. Встановіть Node.js LTS: https://nodejs.org/
2. Розпакуйте архів і відкрийте папку `valilily-store` у терміналі.
3. Виконайте:
   ```bash
   npm install
   npm run dev
   ```
4. Відкрийте адресу, яку покаже Vite (зазвичай `http://localhost:5173`).

## Публікація на GitHub Pages
1. Створіть на GitHub новий репозиторій, наприклад `valilily-store`.
2. Завантажте в нього **вміст** цієї папки (не сам ZIP).
3. Переконайтеся, що основна гілка називається `main`.
4. Відкрийте репозиторій → **Settings → Pages**.
5. У розділі Build and deployment виберіть **GitHub Actions**.
6. Перейдіть у вкладку **Actions**. Після push автоматично запуститься workflow `Deploy ValiLily to GitHub Pages`.
7. Після успішного завершення відкрийте посилання на сайті в Settings → Pages.

## Зображення
Фотографії завантажуються з Unsplash через прямі посилання. Для публічного комерційного використання перевірте умови ліцензії кожного зображення та за потреби замініть їх власними фотографіями або файлами з підтвердженими правами.

## Структура
- `src/main.jsx` — компоненти, логіка каталогу, кошика й форм;
- `src/products.js` — дані товарів;
- `src/style.css` — стилі й адаптивність;
- `.github/workflows/deploy.yml` — автоматична публікація;
- `index.html` — базові метадані й підключення шрифтів.
